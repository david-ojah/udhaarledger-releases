# UdhaarLedger

An offline-first credit and debit ledger for small shops. Track customer dues and
payments in English or Assamese, on Android and Windows.

## Highlights

- Customer ledger with credit and payment entries, running balances, and reports.
- English and Assamese, with light, dark, and system themes.
- Four-digit PIN with optional fingerprint or face unlock.
- Recovery code for a forgotten PIN and for restoring on a new device.
- Encrypted portable backups that can be moved between devices.
- Optional cloud sync with manual **Save to cloud** and **Sync now**.
- Opt-in daily cloud save at a time you choose.
- Optional password-free restore using your cloud account.
- In-app update checks; updates are never forced.

## Privacy and security

The ledger lives on your device. Optional cloud sync uploads only an encrypted
snapshot, never plaintext ledger data. The app does not include advertising,
analytics, or crash-reporting SDKs.

See [Privacy](docs/PRIVACY.md) for details, including the trade-off of
password-free restore.

## Closed source

UdhaarLedger is closed source. This repository hosts documentation, release
binaries, and the issue tracker only. No application source code is published
here. The binaries are provided as-is, and no source-code license is granted.
