# Security policy

## Supported versions

Security fixes are provided for the latest released version. The current release
is listed on the [Releases page](https://github.com/david-ojah/udhaarledger-releases/releases).

## Reporting a vulnerability

Please use
[private vulnerability reporting](https://github.com/david-ojah/udhaarledger-releases/security/advisories/new).
Do not open a public issue for a security problem.

Include:

- the app version and platform;
- steps to reproduce;
- the impact you believe is possible; and
- any relevant screenshots or logs, with personal data removed.

Do not include real customer names, balances, PINs, recovery codes, account
passwords, or unredacted backup files.

## Scope

This policy covers the Android APK, the Windows build, cloud sync, backup and
restore, and the in-app update mechanism.

## Out of scope

- Devices that are already rooted, jailbroken, or compromised.
- Attacks that require the recovery code, account password, or an unlocked device.
- Reports about third-party services used for sign-in or downloads.
