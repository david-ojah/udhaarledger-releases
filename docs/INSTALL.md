# Installation

## Android

Requirements: Android 7.0 (API 24) or newer.

1. Download
   [udhaarledger.apk](https://github.com/david-ojah/udhaarledger-releases/releases/latest/download/udhaarledger.apk).
2. Open the downloaded file from your browser or file manager.
3. If Android asks, allow installs from that app for this one time.
4. Install and open UdhaarLedger.
5. Create a four-digit PIN.
6. Save the recovery code shown on screen. It is displayed only once and is the
   key to restoring your data.

If Play Protect warns about an app installed outside Google Play, review the
warning and continue only if the file came from this page.

### Updating on Android

Install the newer APK over the existing app. Your ledger stays in place. To check
from inside the app, open **Settings → Check for updates**.

If Android reports a signature mismatch, the existing installation came from a
different build. Export an encrypted backup first, uninstall the old app, install
the new APK, and restore the backup with your recovery code.

## Windows

Requirements: Windows 10 or 11, 64-bit.

1. Download
   [udhaarledger-windows.zip](https://github.com/david-ojah/udhaarledger-releases/releases/latest/download/udhaarledger-windows.zip).
2. Extract the whole ZIP to a folder. Do not run the app from inside the ZIP.
3. Run `khata.exe`.
4. If SmartScreen appears, choose **More info → Run anyway** only if the ZIP came
   from this page.
5. Create a four-digit PIN and save the recovery code.

### Updating on Windows

Download and extract the newer ZIP, then replace the old folder contents. Your
ledger is stored in your Windows user profile and is not removed by replacing the
app files.

## First launch checklist

- Set a PIN you can remember.
- Store the recovery code in a password manager or on paper, away from the device.
- Export an encrypted backup after adding important entries.
- If you use cloud sync, sign in and run **Save to cloud** once.

See [Recovery and PIN help](RECOVERY.md) or open an
